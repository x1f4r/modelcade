## liquid-glass-react

The slider motion adapts the directional, distance-faded deformation principle and restrained default elasticity from [rdev/liquid-glass-react](https://github.com/rdev/liquid-glass-react). The extension uses its own vanilla JavaScript and CSS implementation; no React component or runtime dependency is bundled.
